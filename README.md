# Ulgamdagal AI Chat

ИИ-чат для WordPress с поддержкой каталога WooCommerce и передачей диалога живому оператору в Telegram.

## История версий

### 1.0.0

- Обновлены описание плагина, имя автора и ссылка на сайт автора.

### 1.0.1

- Улучшена работа чата при одновременных обращениях посетителей.
- Из поиска по каталогу исключены неопубликованные товары и товары, защищённые паролем.

### 1.0.2

- Если сообщение не отправилось из-за временного ограничения, набранный текст остаётся в поле ввода.
- При обрыве связи чат продолжает искать ответ на уже отправленное сообщение.

### 1.0.3

- Если сообщение точно не отправилось, его можно отправить повторно вручную. Набранный текст сохраняется.
- Улучшена обработка повторных сообщений в диалогах с оператором.

### 1.1.0

- Обновлены настройки плагина и журнал диалогов в WordPress.
- Улучшена навигация по разделам и отображение на телефоне.
- Очистка журнала вынесена отдельно от фильтров.

### 1.1.1

- Исправлена синхронизация материалов: они отправляются из WordPress даже при отключённом удалённом редактировании.

### 1.1.3

- Настройки и журнал объединены в меню ULGA AI Assistant. Операторам доступен журнал.

### 1.1.2

- Добавлены автоматические обновления плагина через GitHub.
